تنظیم اتصال

این صفحه کاملاً استاتیک است و روی GitHub Pages اجرا می‌شود؛ GitHub Pages نمی‌تواند کد سرور اجرا کند. برای گفتگوی واقعی، نشانی یک واسط را اینجا بگذارید — یا اتصال مستقیم را امتحان کنید.

مسیرهای اتصال (به همین ترتیب امتحان می‌شوند)
  1. اتصال مستقیم به Duck.ai — همین صفحه توکن x-vqd-4 را می‌گیرد و چالش x-vqd-hash-1 را داخل مرورگر حل می‌کند. بدون واسط.
  2. سرور واسط — فقط اگر بالا گذاشته باشید (app.py یا worker.js).
  3. مسیر پشتیبان — یک سرویس مدل عمومی با CORS، برای وقتی که Duck.ai در دسترس نیست. متن پیام‌ها در این حالت به همان سرویس می‌رود.
